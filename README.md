## What Ambient Forge Does

Ambient Forge creates calm, open-ended musical textures inside a web browser. Its generative approach is suited to ambient composition, fast musical experiments, meditation soundtracks, background listening, and early-stage sound design.

The application can also serve as a starting point for a broader production workflow. MIDI export makes it possible to move generated ideas into external music software, while descriptive filename metadata helps organize exported variations. Since the workflow is not tied to one particular DAW, you can continue editing, arranging, and layering the material in the environment you already use.

## Using the App

1. Load Ambient Forge in a supported browser.
2. Generate material and listen through the changing musical output.
3. Export a MIDI file whenever you want to develop the result in a DAW.
4. Refer to the metadata in the exported filename when organizing versions and alternate takes.
5. Bring the MIDI into your chosen music software for arrangement, mixing, or further editing.

A common process looks like this:

- Generate and explore a passage in the browser
- Select a variation worth developing
- Export it as MIDI
- Open the MIDI in a DAW
- Extend the composition with more instruments or processing
